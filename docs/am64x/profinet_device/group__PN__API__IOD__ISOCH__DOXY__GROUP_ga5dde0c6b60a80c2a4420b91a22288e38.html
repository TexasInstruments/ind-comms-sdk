◆ PN_API_IOD_activateIsoGpioObj()

uint32_t PN_API_IOD_activateIsoGpioObj ( PN_API_IOD_Handle_t *const  pnHandle,
const uint32_t  nsDelayTime,
const uint32_t  nsDurationTime,
PN_API_IOD_IsoObjHndl_t *  pObjHandle 
)

Configures a comparator to generate a pulse on a chosen GPIO after a specific delay to NewCycle. The service scans for an available object, sets it up and returns an object handle. If multiple events are requested it is important to setup the event with the lower delaytime first.

Parameters
[in]pnHandleProfinet API Handle.
[in]nsDelayTimeDelay value added to new cycle in nsec.
[in]nsDurationTimePulse duration in nsec.
[out]pObjHandleReturn handle to given address, used by PN_API_IOD_freeIsoObj().
Returns
result of the operation as uint32_t.
Return values
PN_API_OKSuccess.
PN_API_NOT_OKSomething went wrong.
PN_API_ERR_PARAMInvalid parameter.
Example
#include "pn_api_iod_isoch.h"
void afterIsrCallback()
{
// do after ISR callback work
}
PN_API_IOD_Handle_t* pnHandle = NULL;
uint32_t status;
PN_API_IOD_IsoObjHndl objHandle;
pnHandle = PN_API_IOD_new();
status = PN_API_IOD_activateIsoGpioObj(pnHandle, 0, 4000, &objHandle);
